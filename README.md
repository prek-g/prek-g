## Featured Projects:

Real Estate Market Analysis in Albania  
Developed a data pipeline analyzing Albanian real estate prices (2015–2025) by scraping listings from MerrJep using Python, transforming the data in Databricks with PySpark, and visualizing insights in Power BI. Addressed significant data quality issues missing values, invalid listings, and extreme outliers by applying statistical filtering to produce a realistic price per square meter trend analysis by city.  

[Full Project](https://github.com/prek-g/databricks-real-estate-albania).

Finance ETL Pipeline  
Built an ETL pipeline in Databricks processing raw JSON data through Bronze, Silver, and Gold layers with Delta Lake. Implemented idempotent ingestion, deduplication, CDC, and SCD1/SCD2 logic for dimensional modeling, producing a star schema with surrogate keys and a high-volume transaction fact table.  
[Full Project](https://github.com/prek-g/databricks-pipeline-architecture).
